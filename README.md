## 📖 遊戲介紹與玩法指南（大亂鬥 Brawl）

### 1. 故事與勝利目標
神秘的 Q 版動物殭屍大軍佔領了 **台北、京都、上海** 三座 3D 繪本城市小行星！  
每座小行星上共有 **13 座知名城市地標建築**（如台北 101、總統府、金閣寺、東方明珠等），未攻佔的建築會不斷湧出動物殭屍。  
玩家必須帶領寶可夢連線小隊穿梭球面戰場，將 **全部 13 座建築攻佔並淨化為我方自動能量砲台**，即可過關晉級下一座更艱難的城市小行星！

### 2. 🐾 血量即隊伍（100 HP ＝ 10 隻主角連線）
- 開局擁有 **`100 HP`（10 隻 3D 寶可夢連線出戰）**，每累計損失 `10 HP` 隊尾會減員 1 隻；隊伍存活隻數越多，攻速加成越高。
- **❤️ 紅蓮回血寶石**：恢復 `+10 HP`，立即在隊尾補回 1 隻歸隊隊友。
- **👑 黃金擴編特殊寶石**：永久提升隊伍上限 `+10 HP`（多連接 1 隻主角），三關上限分別為 **第 1 關 12 隻 → 第 2 關 14 隻 → 第 3 關 16 隻**。

### 3. 🏰 時間讀條攻城 ＆ 我方水晶砲台
- 走進未攻佔建築的光環範圍內即開始 **時間讀條佔領（0% → 100%）**，離開光環進度會保留不歸零。
  - **第 1 關 台北**：`8 秒` ／ **第 2 關 京都**：`11 秒` ／ **第 3 關 上海**：`14 秒`
- **⚠️ 殭屍干擾**：若光環內同時擠進 3 隻以上殭屍，佔領速度會降至 `0.65x`，必須一邊用武器清怪一邊守圈。
- **🦍 50% 護衛隊長**：佔領達 `50%` 時建築會跳出 **猩猩殭屍隊長**，擊殺必掉黃金擴編特殊寶石與精華！
- **🎆 100% 攻佔成功**：建築上方施放 **三連發 3D 空中煙花**，並升起我方 **3D 水晶能量砲台**，自動鎖定周圍殭屍開砲協防！

### 4. ⚔️ 4 種 3D 武器與限時精華升級
場上同時只裝備 **一種主武器**，主角左右兩側會懸浮對應的 3D 武器模組，地面顯示可視攻擊範圍圈；撿到不同武器時會**暫停遊戲詢問是否更換**，更換後**完整繼承目前累積的火力、攻速與階級比例**！

| 武器名稱 | 3D 造型與攻擊特色 |
| :--- | :--- |
| **🌀 迴旋星環刃**（初始） | 多段水晶巨劍環繞主角切割與擊退，兩側懸浮浮游劍匣 |
| **⚡ 追蹤雷羽鏢** | 紫電雙翼機砲自動鎖定範圍內最近敵人連射 |
| **🔥 烈焰震地波** | 雙環陀螺爐心週期性釋放 360° 大範圍震地衝擊波 |
| **☄️ 貫穿星能砲** | 雙管脈衝磁軌砲朝前方發射高傷貫穿光束 |

- **✨ 地上三種精華（限時 12 秒，最後 3.5 秒閃爍提醒）**：
  - 🟢 **階級精華**：提升武器階級（最高 `Lv.10`）
  - 🔵 **疾風精華**：提升武器攻速（上限 `250%`）
  - 🟠 **狂暴精華**：提升武器火力（上限 `300%`）

### 5. 🧟‍♂️ 6 種 Q 版動物殭屍圖鑑
- 🐶 **柴犬殭屍（暖橘）**：速度靈活的基礎突擊怪
- 🐧 **企鵝殭屍（深藍）**：常以 2 隻成群結隊湧出
- 🐰 **跳跳兔殭屍（桃粉）**：週期性往前跳躍突進
- 🐼 **熊貓殭屍（炭黑）**：高血量肉盾、具備高擊退抗性
- 🦊 **暗影狐殭屍（霓虹紫）**：第 2、3 關高移速菁英，高機率掉落精華與特殊寶石
- 🦍 **猩猩殭屍隊長（熔岩紅）**：建築 50% 進度躍出的巨型護衛，擊殺必掉擴編特殊寶石

## 🛠️ 本機開發與打包指令

```bash
# 安裝套件
npm install

# 啟動開發伺服器（Vite）
npm run dev

# 啟動同網域手機測試與 APK 下載伺服器（Port 8080）
node serve_apk.js

# 打包生產版網頁（輸出至 ./dist，含 / 與 /brawl/）
npm run build

# 打包大亂鬥 Android APK（需本機 Android SDK Build-Tools 與 JDK）
powershell -ExecutionPolicy Bypass -File .\build_brawl_apk.ps1
```
